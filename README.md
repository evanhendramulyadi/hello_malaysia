<h1 align="center">Hello Malaysia</h1>

Hello Malaysia is an educational and exploratory mobile application built with Flutter, designed to showcase Malaysia's rich culture, renowned tourism destinations, geography, culinary traditions, inspiring figures, and demographic diversity through an intuitive and visual experience.

This project was initiated as a **Project-Based Learning (PjBL)** assignment at **SMK Pariwisata Metland School**, represented by **Kelompok Malaysia**—a collaborative multidisciplinary student group bringing together talents across multiple vocational disciplines.

## ✨ Key Features

- **Interactive Exploration Hub**: Seamless navigation across Malaysia's key highlights including Culture, Tourism, Geography, Culinary, Inspiring Figures, Demography, and Project Contributors.
- **Multimedia Experience**: Integrated introductory video spotlight featuring Prime Minister Anwar Ibrahim upon startup, paired with rich visual infographics.
- **Tourism & Itineraries**: Detailed destination highlights with an interactive expandable trip itinerary and pricing breakdown.
- **Cultural & Demographic Insights**: In-depth coverage of traditional religious festivities, landforms, territorial boundaries, ethnic diversity, and iconic culinary items like Nasi Lemak and Teh Tarik.
- **Custom Navigation Architecture**: Responsive drawer and persistent bottom navigation bar featuring state-aware active indicators and smart back-navigation handling.
- **Consistent Thematic UI**: Tailored visual identity featuring a signature navy (`#012B47`) and warm cream (`#F8F0E5`) color palette optimized for portrait mobile screens.

## 🛠️ Tech Stack

- **Flutter**: Cross-platform framework for building natively compiled mobile applications.
- **Dart (3.x)**: Strongly typed programming language powering application logic and UI.
- **video_player**: Flutter package enabling seamless video playback.
- **flutter_native_splash**: Automated native splash screen generation.
- **flutter_launcher_icons**: Cross-platform launcher icon configuration.

## 💻 Local Setup Instructions

Ensure you have the [Flutter SDK](https://docs.flutter.dev/get-started/install) (3.10.7 or later) installed and configured on your machine.

1. **Clone the repository**:
   ```bash
   git clone https://github.com/evanhendramulyadi/hello_malaysia.git
   cd hello_malaysia
   ```

2. **Install dependencies**:
   ```bash
   flutter pub get
   ```

3. **Run the application**:
   - Connect a physical device or launch an emulator/simulator.
   - Start the app:
     ```bash
     flutter run
     ```
